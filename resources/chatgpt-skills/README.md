# ChatGPT Skill Collection

Three independent Skills with communication depth routed by task. Source files are readable under their individual directories; complete installable ZIPs are in [`downloads/`](downloads/).

## Installable ZIPs

- [Guiding Step-by-Step Processes](downloads/guiding-step-by-step-processes.zip) — current, personalized, complete walkthroughs with checkpoints.
- [Pragmatic Software Engineering](downloads/pragmatic-software-engineering.zip) — simple durable architecture, verification, and comprehensive agent handoffs.
- [Human-Readable AI Outputs](downloads/human-readable-ai-outputs.zip) — consistent, scannable generated feeds, summaries, and dashboards.

Other files:
- [`templates/AGENTS.md`](templates/AGENTS.md) — reusable coding-agent contributor contract; customize before using in a project.
- [`templates/RESPONSE-PREFERENCES.md`](templates/RESPONSE-PREFERENCES.md) — conversational depth rules, separate from task-triggered Skills.
- [`validation-report.json`](validation-report.json) — local structural checks.

Upload each ZIP **separately** to a compatible ChatGPT Skill uploader. To save it on iOS from GitHub, open the ZIP page and choose **View raw** or **Download raw file**, then save to Files.

These files are stored in JAW's GitHub repository; repository storage alone does not install them into ChatGPT or add records to JAW's database-backed Skills catalog.

Validation covers package structure, not live Skill behavior.
